# AI Creative Studio — Premium Affiliate Creative Canvas 🌟

A production-ready, cloud-first AI web application designed entirely from a smartphone interface. This application automatically transforms raw consumer product images into premium, high-converting social media marketing creatives that match luxury fashion brand aesthetics.

---

---

## ⚡ Core Operational Features

- **Automated Foreground Extraction**: Isolates items using matrix algorithms via `NumPy` & `Pillow`.
- **Dynamic Studio Relighting**: Inject custom highlights, exposures, and backlighting flares.
- **Asynchronous Cloud Font Loader**: Streams professional branding typographies from Google Fonts directly into server memory.
- **Multi-Format Export Matrix**: Allows instant local asset rendering in transparent PNG, commercial JPG, or printable vector PDF.
- **Automated Carousel Generation**: Packages multiple image slots into an organized, downloadable `.zip` marketing deck.

## 📱 How to Run and Preview From a Smartphone

### 1. Fire up the Live Environment
Inside your **GitHub Codespaces terminal console tab**, execute this string to fetch software environments:
```bash
pip install -r backend/requirements.txt
```

### 2. Launch the Application Engine
Boot the production-grade server proxy array across internal network boundaries:
```bash
python -m uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

### 3. Review the Workspace Design Live
- Codespaces will pop up a message stating port `8000` is ready. Tap **Open in Browser**.
- In the new browser window, tap your URL address line, append **`/frontend/index.html`** to the end, and hit **Go**.
- Upload a raw photo asset from your mobile camera roll, adjust design styles, and tap **Render Creative Canvas** to watch the studio compose your marketing creatives instantly.
